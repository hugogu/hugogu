### ☀️ [ORBIT](https://github.com/hugogu/orbit) — [orbits.observer](https://orbits.observer)

A browser-based 3D solar system and sky event simulator. Hand-coded WebGL, time range 1700–2200 UTC, 9,096 proper-motion stars, Newtonian N-body sandbox where you can edit any planet's mass or orbit and watch the system evolve.

`TypeScript` `WebGL` `Three.js` `Astronomy`
